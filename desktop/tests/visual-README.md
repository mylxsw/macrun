# 浏览器视觉夹具

## 图标回归检查

- 概览页 `.brand .logo`、其中的图片、右侧文字块的垂直中心应一致；图片不能超出容器，必须加载成功。配对页也检查图片完整位于容器中。
- 发布并签名后，通过系统应用入口启动已安装的 `.app`，确认侧栏图标与两行文字居中。
- 单独核对运行中的 Dock 图标，不能用访达图标代替。关闭主窗口再从 Dock 打开，图标应保持可见；重新启动后也应加载品牌图标。检查时先确认没有运行中的任务。

## 启动夹具

仅用于检查 **真实 React 组件** 的首次入口、迁移对话框、浮条外观、配对第二/三步和错误状态。`visual.html` 先加载 `visual.ts`，安装内存中的 Tauri 接口替身，再加载 `src/main.tsx`；没有另一份界面实现，也没有修改产品入口。正式构建仍只使用 `desktop/index.html`，不会包含此测试页面。

在 `desktop/` 运行 `npm run dev` 后打开：

- `http://127.0.0.1:1420/tests/visual.html`：已有桌面配置且已连接，应进入“概览”。建议视口 1280×900。
- `http://127.0.0.1:1420/tests/visual.html?scenario=v4`：v4 设计评审数据：两台服务器、两个进行中的项目、桌面操作、待确认请求、退出码非零的命令和一次旧的同步超时。加 `&page=tasks|access|desktop|settings` 打开对应页面，加 `&tray=1` 查看网页版菜单栏面板。
- `http://127.0.0.1:1420/tests/visual.html?legacy=running`：桌面配置为空、检测到正在运行的旧版，应进入设置页，顶部显示迁移入口。
- `http://127.0.0.1:1420/tests/visual.html?legacy=stopped`：桌面配置为空、检测到已停止的旧版，同样应进入设置页并显示迁移入口。
- `http://127.0.0.1:1420/tests/visual.html?overlay=1`：实际 Overlay 组件，建议视口 600×64。
- `http://127.0.0.1:1420/tests/visual.html?pairing=1`：首次配对，建议视口 800×580。粘贴 `macrun://fixture/pair?code=UI-REVIEW`，点击“连接”“继续”可检查后续两步。
- 在配对 URL 后加 `&error=pair`、`&error=start` 或 `&error=connection`，分别检查交换、启动、连接检查失败。
- 在旧版 URL 后加 `&error=migration` 检查迁移失败；加 `&error=start` 检查迁移成功后启动失败。每次只使用一种入口参数。

迁移回归步骤：打开旧版入口，点击“迁移”，先取消并确认仍显示旧版提示；重新打开并确认迁移，应显示“迁移完成”和测试备份路径；点击启动桌面连接，应显示启动成功。失败入口确认后应保留错误说明、重试入口和原来的旧版状态。`legacy=running` 与 `legacy=stopped` 均需检查，首次配对与已有配置入口不能受到迁移分流影响。

模拟的 `migrate_legacy` 只修改当前页面内存中的 `settings`、`legacy_detected` 和 `legacy_running`，返回 `/tmp/macrun-visual-fixture/` 下的假备份路径，不创建任何文件。`error=migration` 会抛出测试错误并保持状态原样。迁移不会自动启动；对话框随后复用模拟的 `start_worker`，更新内存中的运行状态和快照，并发送 `worker-state` 事件。`error=start` 会在更新这些状态之前失败。

页面标题明确标注“UI 测试夹具（模拟连接）”。`html[data-visual-ready="true"]` 表示界面已挂载并等待本地字体加载；`window.__MACRUN_VISUAL_FIXTURE__.calls` 保留当前页面的调用记录。刷新页面会恢复初始状态。

所有响应均为明确的测试数据。脚本不连接真实 worker/服务器，不访问钥匙串、系统权限或文件，不执行命令。未支持的操作报错。配对成功截图只证明前端成功状态与跳转，不证明真实网络交换、凭据保存或系统授权。屏幕提示的浏览器截图只证明组件外观；原生窗口置顶、定位、透明度和截图保护仍须在 `.app` 中验证。

## 大数据与异步状态

- `?tasks=1500`：1500 条可分页历史，包含九种状态、三条活动任务、长命令、24 个工作区和测试后端。快照只含最近 200 条与活动任务，完整历史只能从模拟的 `task_list` 读取。搜索 `fixture-task-1500` 应能找到快照范围外的记录；切换九种状态、下一页、详情与输出都应使用真实组件。
- `?tasks=1500&active=250`：250 条活动任务，核对快照超过 200 条时仍保留全部活动任务；`active=0` 可检查大量历史但当前空闲。
- `?tasks=1500&state=paused`：接收已暂停，活动任务保留。
- `?tasks=1500&state=reconnecting`：执行器存在，网络重连中。
- `?tasks=1500&state=offline`：执行器离线，保留过期快照，用于核对操作是否禁用。
- `?state=starting`：模拟执行器等待系统授权；按钮和说明应明确显示正在启动。此固定状态不会真正请求钥匙串，也不会自行完成。
- `?state=offline&delay=800`：点击启动，观察启动提示与重复点击保护；`delay` 为模拟操作延时毫秒数，上限 5000。
- `?tasks=1500&delay=800`：切页、搜索、加载工具或输出期间继续操作，用于检查旧请求是否覆盖当前选择。
- `?error=app_state`：首次加载失败；`?refresh_error=1`：首次读取成功，后续状态刷新失败。
- `?state=offline&error=save_settings`：手动保存失败必须保留草稿。`error` 也支持 `task_list`、`task_detail`、`tools`、`observe`、`restart_backend`、`autostart`、`diagnostics`、`save_preferences` 等操作名。
- `?tasks=1500&permissions=granted`：仅在内存中把两项权限设为已允许，方便检查桌面控制表单；不会更改 macOS 权限。

`task_list` 接受 `limit`、`status`、`query`、`kind` 和 `{started_at, task_id}` 游标，返回 `tasks`、`total`、`filtered_total`、`counts`、`next_cursor`；摘要不携带输出或图片，详情仍通过 `task_detail`。保存设置、偏好、审批、取消、暂停、停止和工具操作也都是内存模拟。日志、诊断、工作区和系统权限的“打开”操作只记录到 `calls` 和 `html[data-fixture-last-action]`，不会启动外部程序。后端配置保存只是测试响应，不检查 TOML 或持久化到磁盘；不能当作原生保存验收。观察操作生成明确的测试任务，不生成或冒充真实截图。

## 设置页按钮验收矩阵

在 1280×900 与 760×580 各检查一次；需要滚动到通用/诊断区域，不能只确认顶部可见。

| 控件                                   | 正常操作                               | 必查异常/恢复                                                          |
| -------------------------------------- | -------------------------------------- | ---------------------------------------------------------------------- |
| 连接/通用/记录/诊断分区链接            | 滚动到对应分区                         | 窄窗口中不挡住关键操作                                                 |
| 迁移、取消、确认迁移、迁移后启动、关闭 | 运行中与已停止旧版均可进入；取消不执行 | pending 不重复提交；失败保留错误；Escape/Tab/回焦可用                  |
| 手动连接配置、收起                     | 展开/收起同一份草稿                    | 快照刷新不覆盖未保存编辑                                               |
| 保存配置                               | 保存后显示新服务器与固定证书           | `delay=800` 期间输入锁定；失败留草稿；编辑令牌路径不再携带旧钥匙串账号 |
| 配对服务器/重新配对                    | 断开状态下进入配对                     | 启动中及已运行时禁用                                                   |
| 启动并连接                             | 等待授权提示后更新状态                 | 启动中不可重复点击；失败可重试                                         |
| 断开连接                               | 无活动任务时断开                       | 有任务或状态不可用时禁用；全部停止后等待任务结束再断开                 |
| 登录时启动、失败通知、自动连接         | 修改一项保留其他偏好                   | 失败不出现伪成功；进行中不重复提交                                     |
| 7/30/90 天保留时长                     | 当前值高亮，提交真实安全设置           | 离线禁用；不覆盖其他安全选项                                           |
| 查看日志、导出诊断包                   | 调用对应原生接口                       | 夹具仅记录调用；真实文件导出需单独原生验收                             |
| 测试连通性                             | 显示四项检查与错误                     | 换服务器/凭据或离线后清除旧结果；旧异步结果不能回填                    |

权限页的目录、审批、预设与桌面分级控件，以及本机页的桌面后端表单由各自组件测试覆盖；本表不把内存接口成功当作系统权限、网络连接或导出成功。
- `?tasks=100&page=performance`：真实性能组件、指标卡片、趋势和详情，响应为模拟指标；可加 `&state=offline` 核对停机历史提示。原生导出窗口需在 `.app` 验收，夹具不生成导出文件。
