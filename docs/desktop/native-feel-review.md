# 操作流畅性与原生菜单栏面板

2026-10-05。用户确认实施此前的三阶段方案：减少实际卡顿、完善主窗口操作反馈、将 macOS 菜单栏面板改为原生控件。主窗口保留现有布局和功能，未修改 v2 设计稿。

## 修改与原因

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| 读取应用状态会在界面线程执行 `launchctl` 等系统查询；每 4 秒重复读取 | 后台读取，系统信息缓存 30 秒；前台定时读取和窗口恢复时刷新，迁移及登录启动修改后失效缓存 | 避免系统进程和文件检查阻塞窗口响应 |
| 每个心跳向所有窗口广播，屏幕提示反复 show/hide | 边框不订阅；仅主窗口及可见提示窗口收快照；提示可见性改变时才调用窗口接口 | 减少无效渲染和原生窗口调用 |
| 切页销毁内容，局部状态和滚动位置丢失 | 访问过的页面保持挂载；隐藏页面跳过 React 更新；各页保存滚动位置 | 切回时保持搜索、详情、编辑和阅读位置 |
| 一个操作等待时，其他按钮一起禁用 | 按操作与任务记录等待状态，重复点击去重；按钮提供等待反馈 | 独立操作仍可使用，紧急停止不被无关请求阻挡 |
| 翻页、筛选和输出刷新期间内容消失 | 保留已确认列表和详情；等待时禁用翻页；输出刷新保留已显示文本 | 减少空白跳变，同时避免使用旧游标连续翻页 |
| 控件可被选成文本，日志全选会包含整页 | 控件使用箭头指针；界面标签不可选，日志保持可选；聚焦日志后 Cmd/Ctrl+A 仅选日志 | 区分界面操作和正文阅读，减少网页式误选 |
| macOS 菜单栏弹出 Webview | 使用 AppKit `NSPanel`、`NSVisualEffectView`、`NSButton`、`NSSwitch` 和系统字体 | 采用系统控件、圆角、阴影、焦点和键盘行为 |

主窗口按钮仅使用 90 ms 颜色过渡和即时按下反馈，开关滑块 140 ms；未增加页面位移动画。系统“减少动态效果”关闭这些过渡和面板淡入。

## 原生面板

- 宽度固定为 352 pt，高度随任务变化；原生透明窗口和裁切后的圆角材质统一边缘。
- 原生开关采用系统强调色，状态来自执行器确认。请求期间禁用对应控件，并显示等待或具体错误。
- 优先展示待确认任务，最多三条活动任务；可直接打开任务详情，允许一次、15 分钟内同类、拒绝、停止、暂停、桌面总开关和退出均接入原有 Rust/IPC 流程。
- Escape、重复点击菜单栏图标、点击其他窗口可收起。Escape 和主动切换关闭时恢复此前的应用窗口焦点；点击外部窗口不主动抢回焦点。
- 审批等待、运行任务和退出确认保持原有安全语义。其他平台继续使用 Webview 菜单栏实现。
- 隔离 debug 副本使用 `MACRUN_DESKTOP_DATA` 时可与正式应用共存，避免占用正式实例和全局停止快捷键；release 始终保留单实例及快捷键保护。
