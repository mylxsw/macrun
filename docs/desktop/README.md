# 桌面客户端规划与设计

状态：规划与交互原型，尚未实现 Tauri 客户端。记录日期：2026-10-04。

本目录保存本轮讨论的产品方向、技术选择、执行建议与设计稿。明确区分已确认决定、建议方案、待确认细节；不得把原型表现当作已经发布的功能。

## 已确认方向

- 当前优先让开源用户方便地安装和使用，商业化方案暂缓，不作为本轮开发目标。
- 增加有界面的桌面应用，平时常驻 macOS 菜单栏，可查看连接、任务与调用统计。
- 由桌面应用管理本机执行程序，减少用户手动安装系统服务的步骤。
- 桌面框架选择 **Tauri**，保留现有 Rust 核心；不采用此前讨论的 SwiftUI 或 Flutter 方案。
- 架构考虑 Windows 扩展，避免只适配 macOS；当前尚未承诺 Windows 发布日期及功能完整度。
- 开发前先提供可交互设计稿。本次只归档方案和原型，不启动正式客户端开发或生产部署。

## 体验原型

下载 `prototype/index.html`，用桌面浏览器打开。GitHub 文件页面只显示源码。

1. 点击系统栏中的 `⌁`，展开快捷面板。
2. 暂停接收新任务，再恢复；执行中任务应保留。
3. 打开任务详情，点击“模拟任务完成”，观察统计和记录变化。
4. 在活动记录中筛选、搜索，查看失败原因。
5. 切换顶部的首次连接、连接中断场景。
6. 切换 macOS / Windows，观察菜单栏与托盘位置变化。
7. 关闭主窗口，使用托盘重新打开；退出后使用“重置演示”恢复。

所有数据均为示例。不会连接服务器、执行系统命令或持久保存凭据，请勿输入真实密钥。顶部平台与场景选择属于设计评审工具，不是正式产品功能。
