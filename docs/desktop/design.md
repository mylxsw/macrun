# 桌面交互设计 v1

状态：设计提案，已交付可交互原型，尚未获得最终视觉确认。Tauri 框架选择已确认。

## 信息结构

主窗口提供三个入口：概览、活动记录、设置。菜单栏／托盘提供日常快捷操作。当前采用浅色、低饱和绿色、系统字体和紧凑布局；具体颜色与尺寸仍可调整。

### 菜单栏／托盘面板

按优先级显示：连接状态、本机执行程序状态、当前任务、今日统计、最近活动。提供暂停／恢复、重连、打开主窗口、设置及退出。

macOS 面板从顶部菜单栏展开；Windows 从底部托盘展开。两端共享内容，保留平台惯用窗口操作。原型 Windows 模式仅为位置和内容预览，不代表原生托盘已经实现。

### 概览

- 服务器及连接状态。
- 今日任务、成功、失败三个数字。
- 当前任务类型、项目、已耗时和详情入口。
- 最近活动及“查看全部”。

### 活动记录与详情

支持全部／执行中／成功／失败筛选与任务名称、项目、类型搜索。详情显示任务编号、工作目录、命令或操作、耗时、结果和输出，可复制用于排障。

不在快捷面板暴露完整命令和输出。失败后显示原因；不要默认提供自动重试有副作用操作的按钮。未知、取消、超时等实际协议状态需要在开发前补充设计，不能强行归入失败或成功。

### 设置与首次连接

设置包含服务器地址、设备名称、凭据、连接测试、登录时启动、自动连接、桌面后端与权限状态。

首次连接单独展示地址、凭据及服务器证书。原型只选择示例证书；正式版需要真实证书导入、校验和更换流程。原型设置页暂未包含完整证书管理、后端配置、版本和诊断导出界面，开发前补齐。

## 状态与操作规则

| 状态／操作 | 设计行为 |
| --- | --- |
| 已连接 | 可以接收新任务，显示当前执行情况 |
| 暂停接收 | 停止接受新任务，正在执行的任务继续；明确显示仍在运行的数量 |
| 连接中断 | 提示原因与重连入口，执行中任务显示状态待确认，不自动重新提交 |
| 恢复连接 | 查询原任务结果、补齐事件；不得把连接恢复等同于任务成功 |
| 关闭窗口 | 保留托盘及 worker；托盘可重新打开窗口 |
| 退出 | 有执行中任务时提醒；正式版明确中断与清理策略 |
| worker 异常 | 分别展示本机程序故障与服务器断线，提供诊断入口 |
| 桌面权限不足 | 命令能力与桌面能力分别展示，不把整机状态误报为不可用 |

暂停需要协议与执行端真正支持。桌面程序崩溃后如何清理 worker、何时允许自动重启，需要技术验证；原型不证明这些行为。

## 统计口径

建议按唯一任务编号计数，重试查询、心跳、重复消息不增加任务总数。任务类别分为命令、文件和桌面操作。成功和失败只统计确定的终态；执行中、未知、取消另行区分。

“今日”建议按本机时区和任务接收时间归属；跨午夜、重连补录、历史保留与去重持久化仍待接口设计确认。当前原型只有六条模拟数据，刷新会重置，不作为存储实现。

## 原型交互与限制

- 顶部平台／场景切换、重置和“模拟任务完成”仅用于评审，正式产品移除。
- 设置、权限检查和连接均为模拟；不会改系统设置，也不保存秘密。
- 原型支持详情弹窗 Escape 关闭和焦点循环；仍需实际键盘与辅助功能检查。
- 适配窄窗口不等于已验收手机；首版目标是桌面。
- 未做真实浏览器视觉验收，原因和逻辑检查入口见 [目录说明](README.md)。

## 进入开发前需确认

1. 当前整体视觉风格、菜单栏面板密度和默认主窗口行为。
2. 前端框架、worker 通信及历史记录保留规则。
3. 暂停、退出、任务未知／取消的协议语义与界面表现。
4. 证书管理、凭据安全存储、后端配置和诊断页面。
5. Windows 首版范围及验收设备；桌面自动化是否后置。
