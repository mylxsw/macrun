# 界面与交互验收

2026-10-04。用户要求全面检查 UI、操作流畅性、大数据列表、按钮、远程控制、截图及权限。沿用 [v2 七个画板](ui-review/README.md)，不修改设计稿。

## 本轮发现与修复

| 问题 | 修复与验收重点 |
| --- | --- |
| 任务页只能看到最近 200 条，搜索不到更早记录 | 增加完整历史的游标分页，每页 50 条；全量筛选计数；输出和截图按需获取。 |
| 长命令撑坏审批栏、窄窗口任务列表和详情 | 限制网格子项最小宽度；审批命令换行并限制高度，按钮保留可见；检查 760×580 与 1280×900。 |
| 等待钥匙串时像没有反应 | 原生导出启动状态并发送事件；首页与设置显示等待说明，禁止重复启动。 |
| 普通命令的“在终端打开目录”被误判为未知工作区 | 原生使用任务编号核验真实工作目录，工作区卡仍核验同步根目录。 |
| 后台读取状态影响全局按钮，旧响应可能覆盖当前选择 | 只读查询使用独立的加载和错误状态；忽略过期响应，限制同时进行的操作。 |
| 后端截图与历史详情读取失败后仍反复查询 | 显示具体失败及重试；终态停止查询；损坏或不支持的图片明确提示。 |
| 失败任务详情被误判为接口失败，工具错误正文丢失 | IPC 区分请求错误字符串与任务错误对象；详情保留最后 8 KB 工具文本，不缓存图片。 |
| 工具列表只读取第一页、切页后旧请求仍弹窗 | 支持继续读取与累计计数；切页、关闭和 Escape 后忽略旧返回，检查会话是否变化。 |
| 只显示“找到窗口”而漏掉编号，回放详情在屏幕下方 | 增加有限长度的结构化结果预览；选中回放后滚动到详情，后台刷新不抢滚动。 |
| 权限显示容易被理解成后端已获授权 | 明确当前检查仅属于 Macrun；桌面后端权限须独立核实。 |
| 手动配置保存可能覆盖新编辑，换令牌仍带旧钥匙串账号 | 保存期间锁定相关表单；显式更换令牌来源；配置变化后清除旧连通性结果。 |
| 错误提示留在长页顶部，操作完成后状态刷新失败像操作失败 | 错误随滚动保持可见；区分操作失败与刷新失败，避免引导重复提交。 |

## 测试与性能

- `cd desktop && npm test`：11 项 Node 测试、75 项组件测试全部通过。
- `make check`：33 项 Rust 测试、格式检查与 Clippy 通过；桌面原生 16 项测试及 Clippy 通过。
- Debug 和 release 应用均构建成功；最后 release 使用前端资源 `BPBcJ4RD` / `BlWkavAo`。
- 两套隔离真实 CLI 验收通过。1500 条历史以 API 每页 100 条读取，15 页无重复、无遗漏，本次总耗时 0.24 秒；UI 固定每页 50 条。首屏查询约 94–102 ms、缓存后约 18 ms，是本机一次测量，不是性能保证。
- 任务快照只保留最近 200 条摘要和全部活动任务；全历史搜索与计数来自执行器。详情按需读取最后 8 KB 文本，终态缓存最多 100 条；桌面回放独立取最近 8 条，不受最近 200 条命令挤占。
- 历史索引仍需检查任务目录的文件元数据，超大规模的性能上限未验证。没有把 1500 条结果外推为无限数据量保证。

## 2026-10-05：菜单栏和窗口修复

- 图标改为等宽高的圆角终端符号，保留暂停、断线、工作及待确认状态。
- 修复持续闪烁：以前每个快照都依次调用 `set_icon` 和 `set_icon_as_template`，会短暂显示未着色图像；现在仅状态变化时使用原子更新，审批数量单独更新。心跳、延迟和历史数量变化不重绘图标。
- 主窗口单独授予 `core:window:allow-start-dragging`，顶部及品牌区域可作为拖动区域，品牌文字不再被选中。
- 开启的开关统一为绿色，自动生成的深色样式保留该颜色。
- 透明页面的选择器优先于深色根背景，菜单栏窗口关闭原生矩形阴影，避免 CSS 圆角外出现直角边框。
- 验证：前端 104 项、原生 22 项测试通过，原生 Clippy 无警告，debug/release 构建通过。使用隔离原生应用检查深色面板圆角、绿色开关、暂停／恢复及打开主窗口；执行了顶部拖动操作（自动化工具未返回窗口位置，无法量化位移）。真实用户数据和连接配置未修改。
- 修复版已安装至 `/Applications/Macrun Desktop.app`。重新连接需要 macOS 对新构建的钥匙串访问确认；安装时仍等待用户完成该步骤。
