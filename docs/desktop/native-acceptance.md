# 原生验收入口与流程

2026-10-04 更新。当前在本机 Codex 会话中进行 macOS 验收，Computer Use 已能访问 Macrun Desktop。早期 Telegram 会话的工具授权拒绝已经不是当前阻塞，不再要求用户按旧说明重新配置入口。

代码与自动化通过不等于原生视觉或全部系统行为通过。各能力状态见 [完整验收清单](completion-checklist.md)，上一轮七画板的截图与数据边界见 [v2 界面还原复查](ui-review/README.md)。该复查记录保留了当时的阶段状态；以下是后续验收进展。

## 已有实际证据

- 上一轮查看了全部七个 v2 画板，完成界面还原和对应交互复查。现场、任务、桌面控制、设置、首次配对和菜单栏使用真实 Tauri 调试应用；浮条外观及配对成功后两步使用真实组件的浏览器夹具。原生浮条的截图保护、跨屏定位等行为不由浏览器截图证明。
- 本机旧服务已通过桌面迁移流程切换到新版，保留了原连接凭据、1495 条任务与 20 份同步状态。迁移后的只读核验确认旧任务和同步状态原文件保持不变，原目录与停用的启动配置仍可用于恢复；无需重新配对。
- 用户完成 macOS 钥匙串授权后，已确认桌面应用能取回凭据、连接状态为 `connected`、握手检查通过，核验时活动任务数为 0。未更改钥匙串授权规则。
- 真实桌面后端读取到 56 个工具，并通过只读检查返回辅助功能及屏幕录制已授权。通过 UI 提交窗口截图后返回 1000×703 图片，已目视检查回显和回放；通过后端点击 Macrun 的任务导航后，页面实际切换且任务成功。键盘输入、拖动和其他应用仍未据此验证。
- 本轮真实原生应用的辅助功能界面已验证任务翻页、搜索快照范围外的旧任务，以及打开旧失败任务详情。它们是交互证据，不能代替像素级视觉复查。
- 通过系统应用入口启动隔离副本后，已补采并查看任务第二页、旧失败详情、桌面控制和设置四张原生截图。界面内容正常，所见区域没有溢出或遮挡；桌面控制与设置仍可向下滚动。任务、服务器与路径是夹具数据；系统权限和登录启动状态仍来自本机，图片未显示凭据或私人桌面内容。
- 最新隔离 CLI 验收通过真实 QUIC 与同用户 Unix IPC，覆盖暂停、去重、同步进度、审批、目录限制、桌面开关、全部停止、凭据管道、父进程退出清理及重启。
- 另用 1500 条隔离任务验证了 200 条近期快照、完整状态统计、15 页无重复游标、历史搜索、文本输出、结构化失败信息、新任务及取消状态更新。列表不带输出或图片，环境变量值保持脱敏；15 页读取耗时为本次测试的 0.24 秒，不作为性能保证。
- 本轮 Rust 测试 33 项、桌面原生测试 16 项通过。前端 11 项 Node 与 75 项组件测试通过。

## 当前尚未完成的复查

本轮重新构建与安装后的最终确认仍在进行。直接从 shell 启动 debug bundle 内的程序时，用户确认窗口实际白屏；辅助功能树仍可访问。同一 debug 二进制复制到隔离应用副本、用 `LSEnvironment` 指定夹具目录并通过系统应用入口启动后，已正常绘制。本轮正以这种启动方式继续截图复查，先前的白底图片不算视觉证据。该对比确定了可用的验收启动方式，尚未定位底层渲染原因；操作步骤见 [UI 截图夹具](../../desktop/scripts/fixture-README.md)。

此前已有本地 ad-hoc 签名验证记录，但它不等同于 Developer ID 签名、公证或正式分发验收。最新安装包的构建、签名检查与实机复查应另记录具体结果。

## 后续验收顺序

每项记录实际操作、系统版本、结果和失败重现步骤。截图必须真正包含待核对界面，且避免邀请、凭据及私人桌面内容。界面夹具使用独立临时数据目录；真实连接的检查不再重复执行迁移，也不改动已保留的旧数据。

| 顺序 | 实际操作 | 通过条件与当前边界 |
| --- | --- | --- |
| 1 | 确认最新安装包；重新采集四页、菜单栏、配对和浮条证据；检查最小窗口及长内容 | 旧轮七画板已有记录；本轮已通过系统应用入口恢复正常绘制，继续以隔离副本复查溢出、遮挡与还原度。 |
| 2 | 隔离邀请完成新的原生配对、连接检查、关闭重开及失效邀请流程 | 现有迁移连接的钥匙串取回和握手已通过；新邀请完整原生流程仍需单独核验。 |
| 3 | 真实界面查看分页、历史输出、工作区，执行批准、拒绝与等待超时 | 原生分页和旧失败详情已可操作，隔离协议行为通过；访达／终端和系统侧效果需按实操结果记录。 |
| 4 | 菜单栏打开、关闭主窗口、暂停、全部停止、停止快捷键与退出 | 旧轮已有隔离交互记录；最新安装包的退出清理、异常恢复和持续运行仍需按具体场景复查。 |
| 5 | 使用真实桌面后端实拍、查看回放并执行明确授权的输入；检查提示与边框 | 56 个工具、真实截图、回放和一次页面点击已验证；键盘输入、拖动、其他应用与屏幕捕获排除仍待验收，不自动重放 `unknown`。 |

| 7 | 在隔离条件下验证失败回滚、注销再登录的自动启动，以及连续异常退出后的有限恢复 | 真实旧配置迁移与保留校验已完成；文件回滚有自动化覆盖，真实 LaunchAgent 失败回滚和注销／登录周期尚未实测。 |

完成修改后运行受影响检查并重新构建。只交付已经有证据支持的范围；未覆盖的原生系统行为、Windows 适配和正式签名／公证应继续明确列为待验收，不能用构建成功替代。
