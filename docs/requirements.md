# macrun 0.2 需求

目标：美国 Linux 上的 Claude Code 可操作中国 Mac mini，完成任意由 agent 组织的开发与验证流程。提供通用能力，不设计编译专用 API。

## 必需能力

1. Mac 主动连接服务器，服务器向本机 Claude Code 提供 stdio MCP。
2. 通用命令、cwd、env、异步任务、日志、退出码、超时及取消。
3. 单向持续同步未提交的源码改动，查询并等待同步完成。
4. 通用本地 stdio MCP 接入，computer use 是可替换的 backend。
5. 文件分块读写、上传下载；返回真实 MCP 图片内容。
6. 网络断线保留任务和 MCP 会话；重连后查询。请求编号去重，无法确认时返回 unknown。

## 第一版范围

单服务器/单 worker，Linux/macOS；QUIC/UDP；watch 轮询；backend 串行调用。命令可并行，由 agent 避免互相冲突。源码与命令解耦，不暗中触发同步。

## 验收

- Agent 用同一请求编号重试，不会产生重复命令或 MCP 操作。
- 命令长于 RPC 往返时间，仍能拿到任务编号并随后查询。
- 杀掉服务器再重启，worker 命令继续，MCP 状态仍在。
- worker 重启后旧运行任务变为 unknown，不自动执行第二次。
- 二进制多块传输一致，文件图片和 MCP 工具图片都能到达 MCP 客户端。
- 新建/修改/删除代码自动同步；失败不会被报告成成功。
- 实际 Mac 图形会话的截图、点击、输入，以及美中两机网络验收，作为独立部署验收，不用 mock 或本地网络结果代替。
